1. 项目在macBook电脑上运行，不是linux
2. 项目代码需要详细注释，使用中文
3. 需要系统环境时先查看系统有没有这个环境，如果没有再安装。比如 node.js、npm、maven，git此电脑已经有了。
4. 修改代码后不需要提交到github上，等说出“提交”两个字的时候再提交到GitHub。
6. 每次完成任务后都要列出你做了哪些内容。
7. 写同样的一个逻辑功能，错误一次就要自己总结记住错误原因，下次再碰到同样的功能，不能出错。
8. 本机系统环境 java 1.8, npm 11.12.1,Apache Maven 3.5.2,mysql  5.6.26,git version 2.37.1,开发项目或者做需求分析时请以这个环境配置选择对应的版本代码进行开发。
9. 如果碰到功能无法实现或者这个功能代码出bug，请换个思路实现，不要直接将此功能代码删除
