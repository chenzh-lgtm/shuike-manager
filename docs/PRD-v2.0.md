## 1. Executive Summary

### 1.1 项目定位
水课管理系统是一套面向高等院校的**教学材料智能化分析与审核平台**。

### 1.2 核心价值
- 线上审核流转替代纸质审批（3天→1天）
- 火山引擎AI自动四维评审（准确率≥85%）
- 多角色Dashboard可视化统计
- 学院级数据隔离

### 1.3 系统规模
- 96个Java文件 + 33个Vue页面 + 19张数据库表
- 50+ REST API
- 5个Docker容器
- 42个自动化测试（100%通过）

## 2. 用户角色

| 角色 | 编码 | 描述 | 核心权限 |
|------|------|------|----------|
| 教师 | TEACHER | 一线授课教师 | 提交材料、查看审核进度、查看对齐分析报告 |
| 二级学院负责人审核员 | COLLEGE_REVIEWER | 学院教学秘书/副院长 | 审核本院材料（含AI评分+文件预览）、Dashboard统计 |
| 教务处 | OFFICE | 教务处工作人员兼系统管理员 | 终审、AI提示词管理、用户管理、材料归档、批量导入、系统配置 |
| 院长/专业负责人 | DEAN | 学院院长/专业带头人 | 人培方案管理、课程标准管理、发起产业需求对齐分析 |

## 3. 核心业务流程

### 3.1 材料提交与审核流程（两级审核）

```
教师提交材料（选择类型+上传文件+关联课程+选择学期）
  → 每个文件独立创建材料记录
  → 自动触发AI四维并发评审（后台异步）
  → 材料状态: AI_EVALUATING → AI_COMPLETED
  → 学院主任审核 → COLLEGE_APPROVED（待教务处终审）
  → 教务处终审 → OFFICE_APPROVED（最终通过）
  任一环节可驳回 → AI_REJECTED
```

### 3.2 AI评审体系

**四维评审标准**（满分100分）:

| 维度 | 权重 | 评审要点 |
|------|:--:|------|
| 内容完整性 | 30% | 课程基本信息、教学目标、教学内容、考核方案、教材信息 |
| 与课程标准匹配度 | 30% | 目标对准度、知识点覆盖度、学时分配、考核一致性 |
| 格式规范性 | 20% | 文档结构、表格规范、文字表述、排版编号 |
| 创新性 | 20% | 教学理念、教学方法、课程思政、信息技术、产学融合 |

**Prompt模板体系**:
- 4种材料类型 × 4个评审维度 = 16个专业Prompt
- 每种类型有专属的评审专家角色设定
- 教务处可在线编辑，自动版本管理（v2.0递增）
- Prompt数据库存储，支持激活/停用切换

**技术实现**:
- 火山引擎方舟API (RestTemplate HTTP POST)
- TransactionSynchronization.afterCommit() 异步触发
- 4个维度 CompletableFuture 并发调用
- 评分<75的维度生成改进建议

### 3.3 权限与数据隔离

| 角色 | 数据可见范围 |
|------|-------------|
| 教师 | 仅查看自己提交的材料 |
| 学院主任 | 仅查看本学院教师提交的材料（按teacher.college_id过滤） |
| 教务处 | 查看全校所有材料 |
| 院长 | 仅查看本学院的人培方案和课程标准 |

### 3.4 产业需求对齐分析

院长选择人培方案 → 火山引擎LLM分析 → 生成8章节报告:
1. 专业概况与产业背景
2. 产业人才需求分析（含岗位分布柱状图+技能雷达图）
3. 课程体系与产业需求匹配度（含核心课重要度排行）
4. 学生学习成果与能力达成
5. 就业前景分析
6. 人培方案与产业需求差距分析
7. 改进建议与改革方向（按优先级+难度分类）
8. 综合评分与结论

## 5. 非功能需求

- 响应时间: 页面加载≤2s，AI评审≤90s，文件上传≤5s
- 并发支持: 50+用户同时在线
- 安全: JWT认证/RBAC权限/操作日志/HTTPS
- 浏览器兼容: Chrome 90+ / Edge 90+ / Safari 14+
