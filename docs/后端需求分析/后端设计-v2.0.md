## 3. 核心架构决策

### AI异步执行方案（最终方案）
问题：@Async自调用失效，子线程读不到事务未提交的数据
解决：TransactionSynchronizationManager.registerSynchronization().afterCommit() → new Thread() → applicationContext.getBean().runEvaluation()

### 学院数据隔离
PhaseMaterialController.reviewerList(): 获取当前用户collegeId → 遍历材料 → 查teacher.college_id → 匹配过滤。OFFICE角色跳过隔离。

### 两级审核状态机
AI_EVALUATING→AI_COMPLETED→COLLEGE_APPROVED→OFFICE_APPROVED（最终通过）。任一环节→AI_REJECTED。

### MinIO文件路径
phase-materials/{materialType}/{yyyy/MM}/{fileName}_{HHmmss}.{ext}

### Prompt模板查询
按scene+materialType+dimension三个维度查询，is_active=1取最新版本。无专用模板时回退scene+dimension通用模板。

## 5. 安全设计

- JWT: AccessToken(2h)+RefreshToken(7d), jjwt 0.11.5
- RBAC: @PreAuthorize方法级注解 + USER_ROLES表
- 数据隔离: Controller层按角色过滤(非OFFICE按collegeId)
- 文件安全: 白名单扩展名 + MinIO预签名URL(2h有效期)
- 操作审计: OperationLogAOP记录所有Controller方法

## 6. v1.0→v2.0 后端变更
- 新增模块: manualreview(两级审核), dashboard(4角色统计), ai(VolcanoEngineClient+PromptBuilder+Parser)
- 重大重写: AiEvaluationService(真实LLM+事务提交后异步), AlignmentService(真实LLM+6000max_tokens), PhaseMaterialService(delete级联清理MinIO+AI记录)
- 新增功能: 级联筛选API(/reviewer/filters), 归档API(/archive), 批量导入(/users/import), 文件下载预览区分inline/attachment
- 兼容性降级: Spring Boot 3.2→2.7, Java 17→8, jjwt 0.12→0.11, jakarta→javax
