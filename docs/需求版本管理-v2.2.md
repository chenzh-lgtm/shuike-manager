### 2.2 系统配置管理

**对应 PRD**: §2.5 US-D2 验收标准"支持配置审核流程"

| 组件 | 文件 | 说明 |
|------|------|------|
| Entity | [SystemConfig.java](backend/src/main/java/com/shuike/manager/modules/systemconfig/entity/SystemConfig.java) | 映射 `system_configs` 表 |
| Mapper | [SystemConfigMapper.java](backend/src/main/java/com/shuike/manager/modules/systemconfig/mapper/SystemConfigMapper.java) | MyBatis-Plus BaseMapper |
| Service | [SystemConfigService.java](backend/src/main/java/com/shuike/manager/modules/systemconfig/service/SystemConfigService.java) | 按 key 读取 (string/int/bool) + 更新 |
| Controller | [SystemConfigController.java](backend/src/main/java/com/shuike/manager/modules/systemconfig/controller/SystemConfigController.java) | `GET/PUT /api/system-configs` |
| API | [systemConfig.ts](frontend/src/api/systemConfig.ts) | 前端 API 模块 |
| 页面 | [SystemConfig.vue](frontend/src/views/office/SystemConfig.vue) | 4 个 tab：审核流程/安全/AI/其他 |

**11 个配置项**：

| 分类 | 配置键 | 默认值 |
|------|--------|:--:|
| 审核流程 | `enable_college_review` | true |
| 安全 | `enable_captcha`, `max_login_attempts`, `lock_duration_minutes`, `jwt_access/refresh_expire` | false/5/15/7200/604800 |
| AI | `ai_temperature`, `ai_default_model` | 0.3/doubao-pro-32k |
| 其他 | `max_file_size_mb`, `max_file_count`, `notification_poll_seconds` | 20/10/30 |

**审核流程配置化**：`enable_college_review=false` 时，AI 评审完成后跳过学院审核，直接到教务处终审。[ManualReviewService.java](backend/src/main/java/com/shuike/manager/modules/manualreview/service/ManualReviewService.java) 读取此配置实现动态状态流转。

## 3. 数据库变更（ECS 部署需同步）

```sql
-- Prompt 模板新增 material_type 列
ALTER TABLE ai_prompt_templates ADD COLUMN material_type VARCHAR(30) DEFAULT NULL AFTER scene;

-- 对齐分析报告新增完整报告 JSON 列
ALTER TABLE alignment_reports ADD COLUMN report_json LONGTEXT DEFAULT NULL AFTER suggestions;

-- 材料附件 material_id 允许 NULL
ALTER TABLE phase_material_files MODIFY material_id BIGINT DEFAULT NULL;

-- 系统配置新增审核流程开关
INSERT INTO system_configs (config_key, config_value, description) VALUES 
('enable_college_review', 'true', '是否启用学院审核环节（关闭后AI评审直接到教务处终审）')
ON DUPLICATE KEY UPDATE config_value=config_value;

SOURCE docs/数据库/prompt_data.sql;
```
