# 水课管理系统 — 前端设计文档 v2.0

> **版本**: v2.0 | **日期**: 2026-06-12 | **前版本**: [v1.0 前端设计](前端设计.md)

## 1. 技术栈

Vue 3.4 + TypeScript + Element Plus 2.7 + Pinia 2.x + ECharts 5.x + Vite 5.x + Axios 1.x

## 2. 设计系统

- **美学方向**: 温暖学术现代主义
- **主色调**: 深黛绿 #1a3c34
- **背景色**: 暖奶油 #faf7f2
- **强调色**: 古铜金 #c8963e
- **字体**: PingFang SC 优先
- **CSS变量**: 30+ 全局变量 (colors/spacing/radius/shadow/transition)
- **Element Plus深度定制**: 按钮/卡片/表格/标签/输入框等全部覆写

## 3. 路由设计（4角色）

| 路由组 | 角色 | 页面数 | 主要页面 |
|--------|------|:--:|------|
| /teacher | TEACHER | 4 | Dashboard, SubmitMaterial(提交教学材料), ReviewProgress(材料审核进度), AlignmentReport |
| /college | COLLEGE_REVIEWER | 2 | Dashboard(5张ECharts), MaterialReviewList(材料审核含AI评分+文件预览下载+审核弹窗) |
| /office | OFFICE | 8 | Dashboard(7张ECharts), AiReviewManage(材料终审含📄预览⬇下载), UserManage, CollegeManage, CourseManage, SemesterManage, PromptManage, MaterialArchive |
| /dean | DEAN | 5 | Dashboard, TalentPlanList/Form, CourseStandardList/Form, AlignmentReport |
| /shared | 所有角色 | 2 | NotificationCenter, ProfilePage |
| /login | 公开 | 1 | LoginPage (Hero+Form双栏) |

## 4. 核心组件

### 布局系统
- MainLayout: 侧边栏(校徽logo+角色菜单+学院名+用户名)+顶栏(面包屑+通知铃铛+用户下拉)
- BlankLayout: 登录页

### 状态管理 (Pinia)
- authStore: token/refreshToken/userInfo(含collegeName/roles)/登录/登出/角色判断
- appStore: 侧边栏折叠

### API层
- Axios实例: 请求拦截器(自动加Bearer token)+响应拦截器(401自动刷新token)
- 8个API模块: auth/teachingPlan/review/talentPlan/aiEvaluation/manualReview/common(含college/course/semester/user/notification/file/phaseMaterial/courseStandard/alignment/prompt)

## 5. 关键交互设计

### 登录页
- 左侧: 深绿渐变Hero区(校徽+v1.0+标题+3条功能特性)
- 右侧: 暖奶油背景登录表单(👤用户名+🔒密码SVG图标)
- 登录成功按角色路由跳转

### 教师提交材料
- 文件上传→对每个文件独立创建材料→自动触发AI评审
- 材料类型下拉(授课计划/教案/课件/考核方案)
- 学期默认选中当前激活学期

### 主任审核弹窗
- 信息条(教师/课程/时间/状态)
- 左栏: AI综合评分仪表盘+4维进度条+分组建议+附件文件列表(📄预览⬇下载)
- 右栏: 审核决定双卡片切换(通过/驳回)+审核意见+修改要求+确认按钮
- 文件预览: PDF新窗口inline打开, Word/DOCX弹窗展示解析文本

### 教务处Dashboard (ECharts 7张图表)
- KPI卡片(材料总数/待终审/已通过/平均分)左侧彩色条
- 各材料类型审核状态(堆叠柱状图)
- AI评分分布(环形饼图)
- 各学院材料统计(横向渐变柱状图)
- 教师提交Top10(横向柱状图)
- 审核流转概览(面积折线图)
- 6种材料类型平均分

### 通知中心
- 分类筛选(全部/未读/新材料/AI评审/审核结果/待终审)
- 卡片式列表(未读左侧蓝边+蓝点)
- 相对时间显示
- 点击跳转业务页+自动标记已读
- 铃铛30s自动刷新

### 材料归档
- 材料类型下拉+已通过/全部切换+搜索框
- 每行显示教师/课程/文件数
- 预览弹窗Tabs切换多文件(PDF提示新窗口/DOCX文本展示)
- 批量下载按钮

## 6. v1.0→v2.0 前端变更
