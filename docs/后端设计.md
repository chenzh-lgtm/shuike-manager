## 1. 技术栈

| 分类 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 基础框架 | Spring Boot | 3.2+ | Java 17 |
| Web 层 | Spring MVC (REST) | — | 内嵌 Tomcat |
| 认证授权 | Spring Security + JWT | — | 无状态认证 + RBAC |
| ORM | MyBatis-Plus | 3.5+ | 简化 CRUD，分页插件 |
| 数据库 | MySQL | 8.0+ | InnoDB 引擎，utf8mb4 |
| 连接池 | HikariCP | — | Spring Boot 默认，高性能 |
| 缓存 | Redis | 7.x | Spring Cache + Redisson |
| 文件存储 | MinIO | — | 兼容 S3 协议 |
| AI SDK | 火山引擎 Java SDK | — | 豆包/DeepSeek 模型调用 |
| 文档解析 | Apache POI + PDFBox | — | Word/PDF 文本提取 |
| 熔断降级 | Resilience4j | — | AI 调用保护 |
| 异步任务 | Spring Async + 线程池 | — | AI 评审异步化 |
| JSON | Jackson | — | Spring Boot 默认 |
| 参数校验 | Jakarta Validation | — | @Valid + 分组校验 |
| API 文档 | SpringDoc (OpenAPI 3) | — | Swagger UI |
| 定时任务 | Spring Scheduling | — | 学期归档 |
| 日志 | Logback + SLF4J | — | 操作日志 AOP |

## 3. 数据库详细设计（DDL）

### 3.1 学院表

```sql
CREATE TABLE `colleges` (
  `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
  `name`        VARCHAR(100) NOT NULL COMMENT '学院名称',
  `code`        VARCHAR(20)  NOT NULL COMMENT '学院代码',
  `description` VARCHAR(500) DEFAULT NULL COMMENT '学院描述',
  `sort_order`  INT          DEFAULT 0 COMMENT '排序',
  `created_at`  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_code` (`code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学院表';
```

### 3.2 用户表

```sql
CREATE TABLE `users` (
  `id`             BIGINT       NOT NULL AUTO_INCREMENT,
  `username`       VARCHAR(50)  NOT NULL COMMENT '用户名',
  `password_hash`  VARCHAR(255) NOT NULL COMMENT 'BCrypt 加密密码',
  `real_name`      VARCHAR(50)  NOT NULL COMMENT '真实姓名',
  `email`          VARCHAR(100) DEFAULT NULL,
  `phone`          VARCHAR(20)  DEFAULT NULL,
  `college_id`     BIGINT       DEFAULT NULL COMMENT '所属学院',
  `avatar`         VARCHAR(500) DEFAULT NULL COMMENT '头像 URL',
  `status`         TINYINT      NOT NULL DEFAULT 1 COMMENT '状态：1-启用，0-禁用',
  `last_login_at`  DATETIME     DEFAULT NULL COMMENT '最后登录时间',
  `created_at`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`),
  KEY `idx_college_id` (`college_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 3.3 用户角色关联表

```sql
CREATE TABLE `user_roles` (
  `id`      BIGINT      NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT      NOT NULL COMMENT '用户 ID',
  `role`    VARCHAR(30) NOT NULL COMMENT '角色编码：TEACHER/COLLEGE_REVIEWER/OFFICE/DEAN',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_role` (`user_id`, `role`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_role` (`role`)

```

### 3.4 学期表

```sql
CREATE TABLE `semesters` (
  `id`         BIGINT       NOT NULL AUTO_INCREMENT,
  `name`       VARCHAR(50)  NOT NULL COMMENT '学期名称（如 2025-2026学年第一学期）',
  `code`       VARCHAR(20)  NOT NULL COMMENT '学期代码（如 2025-2026-1）',
  `start_date` DATE         NOT NULL,
  `end_date`   DATE         NOT NULL,
  `is_active`  TINYINT      NOT NULL DEFAULT 0 COMMENT '是否当前学期',
  `created_at` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_code` (`code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学期表';
```

### 3.5 课程表

```sql
CREATE TABLE `courses` (

```

## 5. 安全设计

### 5.1 JWT 认证流程

```
用户登录
  │
  ▼
POST /api/auth/login
  │
  ▼
验证用户名密码 (BCrypt)
  │
  ▼
生成 AccessToken (2h) + RefreshToken (7d)
  │
  ▼
返回给前端 (前端存 localStorage)
  │
  ▼
后续请求携带 Authorization: Bearer <accessToken>
  │
  ▼
JwtAuthenticationFilter 拦截验证
  │  ├── 有效 → 放行，设置 SecurityContext
  │  ├── 过期 → 返回 401，前端自动调用 /refresh
  │  └── 无效 → 返回 401
  │
  ▼
RefreshToken 换取新 AccessToken（RefreshToken 存储在 Redis）
```

### 5.2 RBAC 权限模型

```
用户 ─── N:M ─── 角色 ─── N:M ─── 权限
                │
                ├── TEACHER         → 授课计划提交、AI评审、查看对齐报告

```

| 角色 | 数据隔离规则 |

### 5.5 接口安全

- 所有写操作（POST/PUT/DELETE）添加 CSRF Token（非浏览器可跳过）
- 敏感接口（登录、修改密码）添加限流：`@RateLimit(maxAttempts = 5, windowMs = 60000)`
- 密码策略：最小长度 8，必须包含字母和数字，BCrypt 加密
- 文件上传校验：白名单扩展名 + 魔数校验
- SQL 注入防护：MyBatis-Plus 参数化查询
- XSS 防护：输入过滤 + 输出编码

## 6. AI 集成设计（核心）

### 6.1 架构设计

```
教师提交材料 → AiEvaluationController.submit()
    │
    ▼
AiEvaluationService.submit()
    │ → 1. 创建 AiEvaluation 记录(PENDING)
    │ → 2. @Async 异步执行 executeAsync()
    ▼
executeAsync() [aiEvaluationExecutor 线程池]
    │ → 3. 从 phase_material_files 读取文档解析文本
    │ → 4. 从 ai_prompt_templates 加载 4 个维度的 Prompt 模板
    │ → 5. PromptBuilder 构建完整的 System + User Prompt
    │ → 6. VolcanoEngineClient 并发调用 4 次 LLM（每个维度一次）
    │ → 7. EvaluationResultParser 解析每个维度的 JSON 结果
    │ → 8. 汇总 4 个维度评分，加权计算总分
    │ → 9. 保存到 ai_evaluations 表
    │ → 10. 发送通知给教师
    ▼
教务处手动复核 → ManualReviewService.review()
```

        // 4. 解析响应: choices[0].message.content

### 6.3 PromptBuilder — Prompt 构建器

文件: `modules/ai/prompt/PromptBuilder.java`

从 `ai_prompt_templates` 表加载模板，进行变量替换：
- `{{materialType}}` → 材料类型中文名
- `{{materialContent}}` → 文档文本（截断到 15000 字）
- `{{courseStandard}}` → 课程标准内容

### 6.4 EvaluationResultParser — 结果解析器

文件: `modules/ai/parser/EvaluationResultParser.java`

解析 LLM 返回的 JSON：
1. 提取 `overall_score`（0-100）
2. 提取 `dimension_scores` 对象
3. 提取 `suggestions` 数组
4. 提取 `summary` 文本
5. 校验评分在有效范围，失败时重试或标记人工评审

### 6.5 异步执行与容错

- **线程池配置**: 核心 2 线程，最大 5 线程，队列 100
- **并发策略**: 4 个评审维度并发调用 LLM，使用 CompletableFuture
- **超时控制**: 单个 LLM 请求超时 60 秒
- **熔断降级**: Resilience4j CircuitBreaker，失败率 >50% 时熔断 30 秒
- **失败重试**: 最多重试 2 次，间隔 2 秒
- **解析失败处理**: JSON 解析失败时尝试用正则提取评分，仍失败则标记为需人工评审

### 8.2 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ApiResponse<Void> handleBusinessException(BusinessException e) {
        return ApiResponse.error(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<Void> handleValidationException(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
            .map(f -> f.getField() + ": " + f.getDefaultMessage())
            .collect(Collectors.joining("; "));
        return ApiResponse.error(400, msg);
    }

    @ExceptionHandler(AccessDeniedException.class)
    public ApiResponse<Void> handleAccessDenied(AccessDeniedException e) {
        return ApiResponse.error(403, "无操作权限");
    }

    @ExceptionHandler(Exception.class)
    public ApiResponse<Void> handleUnknownException(Exception e) {
        log.error("未知异常", e);
        return ApiResponse.error(500, "服务器内部错误");
    }
}
```
