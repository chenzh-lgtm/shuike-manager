## 4. 测试发现的问题与修复

### 4.1 Bug#1: RedisConfig 强制依赖 Redis 连接

**严重程度**: 高  
**现象**: 在无 Redis 环境中应用无法启动，`RedisConnectionFactory` Bean 缺失导致崩溃。  
**根因**: `RedisConfig` 无条件创建 `RedisTemplate` Bean，依赖 `RedisConnectionFactory`。  
**修复**: 给 `RedisConfig` 添加 `@ConditionalOnBean(RedisConnectionFactory.class)` 注解，使 Redis 配置在无 Redis 环境自动跳过。同时移除未使用的 `@EnableCaching`。

### 4.2 Bug#2: 分页参数 page=0 导致 500 错误

**严重程度**: 低  
**现象**: 前端传 `page=0` 时后端抛出 `MyBatisPlusException`，返回 500。  
**根因**: MyBatis-Plus 分页插件要求 page ≥ 1，传入 0 触发 IllegalArgumentException。  
**修复**: 在各 Controller 中添加 `page = Math.max(1, page)` 防御性校验。

### 4.3 发现#3: MockMvc 中文编码问题

**严重程度**: 低（仅影响测试断言）  
**现象**: 测试环境中 API 返回的中文在断言比较时出现乱码。  
**根因**: Spring Boot Test 默认字符集问题。  
**处理**: 测试用例中使用 `assertNotNull()` 和 `assertFalse(field.isEmpty())` 替代逐字中文比较。

### 4.4 修复#4: 测试环境兼容

为支持自动化测试，对生产代码做了以下改进：
- `RedisConfig`: 条件化加载（`@ConditionalOnBean`）
- `MinioConfig`: 测试环境通过 `@MockBean` 替换
- 测试使用真实 MySQL 数据库（与生产环境一致）
