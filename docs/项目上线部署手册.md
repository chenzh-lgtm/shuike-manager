## 1. 前置准备：你的电脑需要什么

### 1.1 检查清单

| 项目 | 最低要求 | 检查命令 |
|------|----------|----------|
| 操作系统 | macOS 12+ / Windows 10+ | — |
| 内存 | 8GB+（Docker 需要 4GB） | — |
| 磁盘空间 | 20GB+ 可用空间 | — |
| Git | 2.x | `git --version` |
| Docker Desktop | 4.x | `docker --version` |

### 1.2 注册阿里云账号

1. 浏览器打开 [https://www.aliyun.com](https://www.aliyun.com)
2. 点击「免费注册」，用手机号注册（支付宝扫码也行）
3. **必须实名认证**（否则无法使用容器镜像服务）
4. 进入 [容器镜像服务控制台](https://cr.console.aliyun.com)，设置登录密码

> 💡 **说明**：阿里云分两个产品：
> - **容器镜像服务 ACR**（免费）— 存放你的 Docker 镜像（类似 GitHub 存代码，ACR 存镜像）
> - **ECS 云服务器**（付费）— 运行你项目的服务器

## 2. 第一步：安装 Docker Desktop

### macOS 安装

```bash
# 方式一：官网下载（推荐）
# 1. 打开 https://www.docker.com/products/docker-desktop/
# 2. 下载 macOS 版本（Apple Silicon 选 Apple Chip，Intel 选 Intel Chip）
# 3. 双击 .dmg 文件，拖到 Applications 文件夹
# 4. 从 Launchpad 打开 Docker Desktop，等待鲸鱼图标变稳定

# 方式二：Homebrew 安装
brew install --cask docker
# 然后从 Launchpad 打开 Docker Desktop 完成初始化
```

### Windows 安装

```
1. 打开 https://www.docker.com/products/docker-desktop/
2. 下载 Windows 版本，双击安装
3. 安装过程中勾选 "Use WSL 2 instead of Hyper-V"（推荐）
4. 如果提示需要 WSL2，按照微软文档安装：
   https://learn.microsoft.com/zh-cn/windows/wsl/install
5. 重启电脑，打开 Docker Desktop，等待右下角鲸鱼图标稳定
```

### 验证安装

```bash
docker --version
# 输出: Docker version 24.x.x

docker run hello-world
# 输出: Hello from Docker!（如果能显示这一行，说明安装成功）

docker ps
# 输出: CONTAINER ID   IMAGE   ...（空列表，表示没有运行中的容器）
```

## 3. 第二步：理解项目部署架构

### 3.1 你项目的 Docker 部署架构

```
  浏览器 (localhost:80)
        │
        ▼
┌──────────────────────────────────────┐
│  frontend (Nginx + Vue 静态文件)       │  ← 端口 80
│  负责展示页面 + /api 代理              │
└─────────────┬────────────────────────┘
              │ /api 请求
              ▼
┌──────────────────────────────────────┐
│  backend (Spring Boot Java)           │  ← 端口 8080
│  负责所有业务逻辑                      │
└────┬──────────┬──────────┬───────────┘
     │          │          │
     ▼          ▼          ▼
┌────────┐ ┌───────┐ ┌────────┐
│ MySQL  │ │ Redis │ │ MinIO  │
│ :3306  │ │ :6379 │ │ :9000  │
│ 数据库  │ │ 缓存  │ │ 文件存储│
└────────┘ └───────┘ └────────┘
```

### 3.2 Docker 概念速查（新手必看）

| 术语 | 通俗解释 | 类比 |
|------|----------|------|
| **镜像 Image** | 一个打包好的软件包，包含代码+运行环境 | 就像 .exe 安装包 |
| **容器 Container** | 镜像运行起来的实例 | 就像双击 .exe 打开的程序 |
| **Dockerfile** | 镜像的"配方"，描述如何构建镜像 | 就像菜谱 |
| **docker-compose** | 一键启动多个容器的编排工具 | 就像"一键开全套厨房设备" |
| **数据卷 Volume** | 容器删除后数据不丢失的存储 | 就像外接硬盘，容器坏了数据还在 |
| **端口映射** | `宿主机:容器` 例如 `80:80` | 就像路由器端口转发 |

## 4. 第三步：本地 Docker 部署（一键启动）

### 4.1 进入项目目录

```bash
# 确认你在项目根目录（包含 docker-compose.yml 的那个目录）
cd /path/to/teacher-file-manager

# 检查关键文件都在
ls -la docker-compose.yml     # 应该存在
ls -la backend/Dockerfile     # 应该存在
ls -la frontend/Dockerfile    # 应该存在
ls -la docs/database.sql      # 数据库初始化脚本
```

### 4.2 一键启动全部服务

```bash
# 构建所有镜像 + 启动所有容器（首次需要 10-20 分钟，之后只要几秒）
docker compose up -d --build

# 你会看到类似输出：
# [+] Building 0.0s (0/0)
# [+] Running 5/5
#  ✔ Container shuike-mysql     Started
#  ✔ Container shuike-redis     Started
#  ✔ Container shuike-minio     Started
#  ✔ Container shuike-backend   Started
#  ✔ Container shuike-frontend  Started
```

### 4.3 查看启动状态

```bash
# 查看所有容器的运行状态
docker compose ps

# 输出类似：
# NAME               STATUS              PORTS
# shuike-mysql       Up 2 minutes        0.0.0.0:3306->3306/tcp
# shuike-redis       Up 2 minutes        0.0.0.0:6379->6379/tcp
# shuike-minio       Up 2 minutes        0.0.0.0:9000-9001->9000-9001/tcp
# shuike-backend     Up 30 seconds       0.0.0.0:8080->8080/tcp
# shuike-frontend    Up 30 seconds       0.0.0.0:80->80/tcp
```

### 4.4 查看实时日志（排查问题用）

```bash
# 查看所有容器日志
docker compose logs -f

# 只看后端日志
docker compose logs -f backend

# 只看 MySQL 日志
docker compose logs -f mysql

# 按 Ctrl+C 退出日志查看
```

□ 1. 打开 http://localhost，看到登录页（左侧深绿色，右侧登录框）

```bash

# 退出
exit
```

## 6. 第五步：推送到阿里云容器镜像服务

### 为什么需要这一步？

> 阿里云 ECS 服务器需要从某个地方"拉取"你的镜像才能运行。
> 阿里云容器镜像服务（ACR）就是一个存放镜像的私有仓库。

### 6.1 在阿里云创建镜像仓库

```
1. 打开 https://cr.console.aliyun.com
2. 点击「实例列表」→「创建个人版实例」(免费)
3. 实例创建完成后，点击「进入实例」
4. 左侧菜单 →「命名空间」→「创建命名空间」
   命名空间名称: shuike
   自动创建仓库: 否
   默认仓库类型: 私有
5. 左侧菜单 →「镜像仓库」→「创建镜像仓库」
   仓库名称: teacher-file-manager-backend
   命名空间: shuike
   仓库类型: 私有
   摘要: 水课管理系统-后端
6. 再次「创建镜像仓库」
   仓库名称: teacher-file-manager-frontend
   命名空间: shuike
   仓库类型: 私有
```

### 6.2 设置阿里云登录密码

```
1. 容器镜像服务 → 左侧「访问凭证」
2. 点击「设置固定密码」
3. 密码: 设置一个你能记住的密码（例如 MyShuike@2026）
4. 保存
```

### 6.3 在本地登录阿里云

```bash
# 替换为你的实际值（在访问凭证页面复制命令）
docker login --username=你的阿里云账号@aliyun.com registry.cn-hangzhou.aliyuncs.com

# 输入刚才设置的固定密码
# 如果看到 "Login Succeeded" 表示登录成功
```

### 6.4 构建镜像并推送

```bash
# 1. 先构建本地镜像（如果还没构建）
cd /path/to/teacher-file-manager
docker compose build

# 2. 给镜像打标签（替换 registry.cn-hangzhou.aliyuncs.com 为你的仓库地址）
#    你可以在阿里云镜像仓库页面找到完整地址

docker tag shuike-backend:1.0 \
  registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-backend:1.0

docker tag shuike-frontend:1.0 \
  registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-frontend:1.0

# 3. 推送到阿里云
docker push registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-backend:1.0
docker push registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-frontend:1.0

# 等待推送完成（会显示进度条）
# 完成后在阿里云控制台 → 镜像仓库 → 镜像版本 中可以看到 1.0 版本
```

## 7. 第六步：阿里云 ECS 服务器部署

### 7.1 购买 ECS 服务器（如果需要）

```
1. 打开 https://ecs.console.aliyun.com
2. 点击「创建实例」
3. 基础配置:
   - 付费方式: 按量付费（测试）/ 包年包月（正式使用）
   - 地域: 选择离你最近的（如 华东1 杭州）
   - 实例规格: 2 vCPU 4 GiB（最低要求）
   - 操作系统: Ubuntu 22.04 / CentOS 7.9
   - 系统盘: 40 GiB
4. 网络和安全组:
   - 勾选「分配公网 IPv4 地址」
   - 安全组开放端口: 80, 443, 22, 8080（后续可以只保留 80 和 22）
5. 登录凭证:
   - 选择「密钥对」或「自定义密码」
   - **牢记密码！**
6. 确认订单，支付
```

### 7.2 连接 ECS 服务器

```bash
# 如果你有公网 IP（假设为 47.96.xxx.xxx）
ssh root@47.96.xxx.xxx
# 输入你设置的密码
```

### 7.3 在 ECS 上安装 Docker

```bash
# Ubuntu 系统
curl -fsSL https://get.docker.com | bash

# 启动 Docker
systemctl start docker
systemctl enable docker

# 安装 docker-compose 插件
apt-get update && apt-get install -y docker-compose-plugin

# 验证
docker --version
docker compose version
```

### 7.4 登录阿里云并拉取镜像

```bash
# 在 ECS 服务器上执行
docker login --username=你的阿里云账号@aliyun.com \
  registry.cn-hangzhou.aliyuncs.com

# 拉取镜像
docker pull registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-backend:1.0
docker pull registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-frontend:1.0
```

### 7.5 在 ECS 上创建 docker-compose.yml

```bash
# 创建项目目录
mkdir -p /opt/shuike && cd /opt/shuike

# 创建 .env 文件（填入你的火山引擎 KEY）
cat > .env << 'EOF'
VOLCANO_API_KEY=ark-206f19bd-c75f-4243-8b65-def780c211f6-504f9
VOLCANO_ENDPOINT=https://ark.cn-beijing.volces.com/api/v3
VOLCANO_DEFAULT_MODEL=ep-20260502165153-5zwf7
JWT_SECRET=shuike-production-jwt-secret-2026-$(date +%s)
EOF

# 创建 docker-compose.yml（ECS 版本，直接从阿里云拉取镜像）
cat > docker-compose.yml << 'EOF'
version: "3.8"

services:
  mysql:
    image: mysql:8.0
    container_name: shuike-mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: shuike@2026
      MYSQL_DATABASE: shuike_manager
      TZ: Asia/Shanghai
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_general_ci
      - --skip-log-bin
    networks:
      - shuike-net

  redis:
    image: redis:7-alpine
    container_name: shuike-redis
    restart: always
    command: redis-server --appendonly yes --requirepass shuike@redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    networks:
      - shuike-net

  minio:
    image: minio/minio:latest
    container_name: shuike-minio
    restart: always
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - minio-data:/data
    command: server /data --console-address ":9001"
    networks:
      - shuike-net

  backend:
    image: registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-backend:1.0
    container_name: shuike-backend
    restart: always
    ports:
      - "8080:8080"
    environment:
      DB_USERNAME: root
      DB_PASSWORD: shuike@2026
      REDIS_HOST: redis
      REDIS_PORT: 6379
      REDIS_PASSWORD: shuike@redis
      MINIO_ENDPOINT: http://minio:9000
      MINIO_ACCESS_KEY: minioadmin
      MINIO_SECRET_KEY: minioadmin123
      VOLCANO_API_KEY: ${VOLCANO_API_KEY}
      TZ: Asia/Shanghai
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/shuike_manager?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
      JWT_SECRET: ${JWT_SECRET}
    depends_on:
      - mysql
      - redis
      - minio
    networks:
      - shuike-net

  frontend:
    image: registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-frontend:1.0
    container_name: shuike-frontend
    restart: always
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - shuike-net

volumes:
  mysql-data:
  redis-data:
  minio-data:

networks:
  shuike-net:
    driver: bridge
EOF

# 启动所有服务
docker compose up -d

# 需要初始化数据库（首次启动 MySQL 自动执行，如果失败则手动执行）
# docker exec -i shuike-mysql mysql -u root -pshuike@2026 < /path/to/database.sql
```

### 7.6 配置安全组（开放端口）

```
阿里云控制台 → ECS → 安全组 → 配置规则 → 添加入方向规则：

端口 80    来源 0.0.0.0/0    HTTP 访问
端口 443   来源 0.0.0.0/0    HTTPS 访问（可选）
端口 22    来源 0.0.0.0/0    SSH 远程连接
```

> ⚠️ **重要**：生产环境建议只开放 80 和 22 端口。不想让公网访问 MySQL(3306)、Redis(6379)、MinIO(9000) 的话不要开放这些端口。

### 7.7 访问你的系统

```
浏览器打开: http://你的ECS公网IP
例如: http://47.96.xxx.xxx

登录账号: admin / 123456
```

## 8. 常见问题排查

### 8.1 构建时下载依赖很慢

```bash
# 使用国内阿里云 Maven 仓库加速
# 后端 pom.xml 已有阿里云配置，如果仍然很慢：
docker compose build --no-cache backend

# Node 使用淘宝镜像（已在前端 Dockerfile 配置 npmmirror.com）
```

### 8.2 容器启动失败

```bash
# 查看失败容器的日志
docker compose logs backend    # 后端
docker compose logs mysql      # MySQL

# 常见原因：
# 1. MySQL 还没启动完成 → 等待 30 秒再试
# 2. 端口被占用 → 修改 docker-compose.yml 中的 ports
# 3. 数据库未初始化 → 手动执行 database.sql
```

### 8.3 端口被占用

```bash
# macOS 查看端口占用
lsof -i :3306
lsof -i :8080
lsof -i :80

# 如果本地已有 MySQL 在运行：
# 方式一：停止本地 MySQL
brew services stop mysql@8.0

# 方式二：修改 docker-compose.yml 端口映射
# 把 "3306:3306" 改为 "3307:3306"，然后用 3307 端口访问
```

### 8.4 MySQL 启动报错 "Table 'shuike_manager.xxx' doesn't exist"

```bash
# 说明数据库未正确初始化，手动执行：
docker exec -i shuike-mysql mysql -u root -pshuike@2026 < docs/database.sql
```

### 8.5 前端页面空白

```bash
# 检查后端是否正常
curl http://localhost:8080/api/auth/login

# 如果返回 "Connection refused"，说明后端没启动
docker compose logs backend

# 如果后端正常但前端代理失败，检查 Nginx 配置
docker exec shuike-frontend cat /etc/nginx/conf.d/default.conf
```

### 8.6 Docker Desktop 提示空间不足

```bash
# 清理未使用的镜像和容器
docker system prune -a

# 在 Docker Desktop → Settings → Resources → Disk image size 可调整
```

### 8.7 如何完全重置环境

```bash
# 停止并删除所有容器、数据卷
docker compose down -v

# 删除镜像
docker rmi shuike-backend:1.0 shuike-frontend:1.0

# 重新开始
docker compose up -d --build
```

## 9. 日常运维指南

### 9.1 日常命令速查

```bash
# ===== 启动/停止 =====
docker compose up -d              # 启动全部服务
docker compose stop               # 停止全部服务（数据不丢）
docker compose down               # 停止并删除容器（数据卷保留）
docker compose down -v            # 停止删除+清空数据库！危险！

# ===== 查看状态 =====
docker compose ps                 # 查看运行状态
docker compose logs -f --tail=50  # 查看最近 50 行日志

# ===== 重启单个服务 =====
docker compose restart backend    # 重启后端
docker compose restart frontend   # 重启前端

# ===== 更新代码后重新部署 =====
docker compose build backend      # 只重新构建后端
docker compose up -d backend      # 更新后端容器
# 注意：需要先推送新镜像到阿里云，ECS 上重新拉取

# ===== 备份数据库 =====
docker exec shuike-mysql mysqldump -u root -pshuike@2026 shuike_manager > backup.sql

# 恢复数据库
docker exec -i shuike-mysql mysql -u root -pshuike@2026 shuike_manager < backup.sql
```

### 9.2 更新部署流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  1. 本地修改代码 │ →  │  2. 重新构建镜像 │ →  │  3. 推送到ACR  │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                 │
┌──────────────┐     ┌──────────────┐     ┌──────▼───────┐
│ 6. 验证功能    │ ←  │  5. 重启容器   │ ←  │ 4. ECS拉取新镜像│
└──────────────┘     └──────────────┘     └──────────────┘
```

**具体命令**：
```bash
# 1. 本地构建
docker compose build

# 2. 打标签
docker tag shuike-backend:1.0 registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-backend:1.0

# 3. 推送
docker push registry.cn-hangzhou.aliyuncs.com/shuike/teacher-file-manager-backend:1.0

# 4. SSH 到 ECS
ssh root@你的ECS_IP

# 5. ECS 上拉取+重启
docker compose pull backend
docker compose up -d backend
```
