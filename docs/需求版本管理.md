## v1.1 → v2.0 重大变更

### 角色体系重构
- v1.1: 6个角色（教师/二级学院审核员/教务处审核员/院长/系统管理员/AI引擎）
- v2.0: 4个角色（教师/二级学院负责人审核员/教务处/院长/专业负责人）

### 审核流程重大变更
- v1.1: 单级审核（仅教务处审核）
- v2.0: **两级审核流程**（学院主任审核 → 教务处终审）
- 新增「材料审核进度」三步条展示（AI评审→主任审核→教务处审核）

### AI 评审系统
- v1.1: 模拟数据，单维度评审
- v2.0: 真实火山引擎LLM调用，**四维并发评审**，16套专用Prompt模板
- 新增 Prompt 在线编辑+自动版本管理
- AI评审异步执行（事务提交后触发）

### 新增功能模块
- 材料归档（教务处按类型/课程/教师筛选，在线预览+批量下载）
- 产业需求对齐分析（LLM生成8章节论文式报告）
- 通知中心全流程通知（材料提交/AI完成/审核结果）
- CSV批量导入用户（含模板下载）
- 学院数据隔离（主任仅见本院材料）
- MinIO按材料类型分目录存储

### 技术架构变更
- v1.1: Spring Boot 3.2 + Java 17
- v2.0: **Spring Boot 2.7 + Java 8**（适配JDK 1.8生产环境）
- 新增 Docker Compose 一键部署
- 新增 42 个自动化测试

### 前端UI变更
- 全新设计系统（温暖学术风格，CSS变量体系）
- 登录页 Hero+表单双栏布局
- ECharts可视化Dashboard
- 文件在线预览（PDF新窗口/Word文本弹窗）

---

> 版本管理规则：重大功能变更升级主版本号，文档修改升级次版本号，Bug修复不升级文档版本。
