
## 4. 发现的 Bug 及修复记录

| ID | Bug | 严重度 | 修复 |
|----|-----|:--:|------|
| BUG-01 | `RedisConfig` 强制依赖 Redis 导致无Redis环境启动崩溃 | 高 | 添加 `@ConditionalOnBean` 条件化 |
| BUG-02 | 分页参数 `page=0` 导致 MyBatis-Plus 500 | 低 | Controller 添加 `if (page<1) page=1` |
| BUG-03 | `@EnableCaching` 加重 Redis 依赖 | 中 | 移除未使用的注解 |
| BUG-04 | AI 评审异步线程事务提交时序问题（已有修复） | 高 | `TransactionSynchronization.afterCommit` |
| BUG-05 | MockMvc multipart 上传中文编码问题 | 低 | 测试用例做兼容处理 |
