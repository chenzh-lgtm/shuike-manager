## 4. 本次测试修复记录

### 4.1 Bug#1: Dashboard API 字段更新未同步到测试（本次修复）

**严重程度**: 中  
**发现日期**: 2026-06-15  
**现象**: `ShuiKeIntegrationTest.testOfficeDashboard` 和 `ClosedLoopIntegrationTest.testClosedLoop2_OfficeDashboard` 均失败，断言 `d.has("collegeCounts")` 为 false。  
**根因**: 6/14 后端 DashboardService 新增了 `collegeMaterialAvgScores`（各学院×材料类型平均分）字段，替换了原有的 `collegeCounts` 字段，但测试用例未同步更新。  
**修复**: 将两个测试文件中的 `collegeCounts` 替换为 `collegeMaterialAvgScores`。

| 文件 | 行号 | 修改内容 |
|------|:----:|------|
| `ShuiKeIntegrationTest.java` | 177 | `d.has("collegeCounts")` → `d.has("collegeMaterialAvgScores")` |
| `ClosedLoopIntegrationTest.java` | 268 | `requiredFields` 数组中 `"collegeCounts"` → `"collegeMaterialAvgScores"` |

**本次错误原因**: 后端 API 变更后未同步更新测试断言，导致字段名不匹配。  
**下次避免方式**: 后端 API 字段变更时，搜索项目全局引用，确保测试文件同步更新。

### 4.2 已知问题：文件上传 Mock 环境报错

**严重程度**: 低（不影响测试结果）  
**现象**: 闭环测试步骤2中 `FileController.upload` 输出 ERROR 日志。  
**根因**: MinIO 客户端被 `@MockBean` 替换，文件上传在 Mock 环境下不支持真实存储。测试中已做兼容处理（`if (uploadedFileId != null)` 跳过文件关联）。  
**状态**: 已知限制，不影响核心业务验证。

### 4.3 已知问题：批量导入重复用户

**严重程度**: 低  
**现象**: 批量导入显示成功 0 / 失败 2。  
**根因**: 测试用户（T998/T999）在上次测试运行中已入库，重复导入被去重逻辑拦截。  
**状态**: 不影响测试结果，属预期行为。
