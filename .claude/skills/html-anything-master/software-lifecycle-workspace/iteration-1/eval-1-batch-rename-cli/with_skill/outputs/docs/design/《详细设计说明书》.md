## 2. 模块 1：配置模型 (config.py) 详细设计

### 2.1 模块概述

定义数据类 `RenameConfig` 和枚举 `RenameStatus`，作为整个系统的配置载体和状态常量。

### 2.2 类/接口定义

```python
from dataclasses import dataclass, field
from enum import Enum, auto
from pathlib import Path

class RenameStatus(Enum):
    """文件重命名状态枚举"""
    PENDING = auto()     # 待执行
    SUCCESS = auto()     # 重命名成功
    SKIPPED = auto()     # 跳过（未匹配正则）
    FAILED = auto()      # 重命名失败（权限等）
    CONFLICT = auto()    # 目标名冲突

@dataclass
class RenameConfig:
    """重命名配置，存储所有用户输入参数"""
    directory: Path
    pattern: str
    replacement: str
    recursive: bool = False
    dry_run: bool = False
    ignore_case: bool = False
    filter_glob: str | None = None
    force: bool = False
    verbose: bool = False

@dataclass
class RenameMapping:
    """单个文件的重命名映射"""
    original_path: Path
    new_name: str           # 仅文件名，不含路径
    matched: bool = False   # 正则是否匹配
    status: RenameStatus = RenameStatus.PENDING

    @property
    def new_path(self) -> Path:
        """计算新文件的完整路径"""
        return self.original_path.parent / self.new_name

@dataclass
class ConflictInfo:
    """冲突信息"""
    target_name: str
    conflicting_paths: list[Path]

@dataclass
class RenameResult:
    """重命名执行结果"""
    success_count: int = 0
    skip_count: int = 0
    fail_count: int = 0
    conflict_count: int = 0
    mappings: list[RenameMapping] = field(default_factory=list)
```

```
function scan():
    files = []
    if config.recursive:
        使用 rglob("*") 遍历所有文件
    else:
        使用 glob("*") 遍历当前目录文件

    for each file_path in 遍历结果:
        if file_path 是文件 and _should_include(file_path):
            files.append(file_path)

    return sorted(files)  // 按路径排序保证确定性

function _should_include(file_path):

    return file_path.match(config.filter_glob)
```

### 4.2 类/接口定义

```python
from config import RenameConfig, RenameMapping, RenameStatus

    def __init__(self, config: RenameConfig) -> None: ...

    def build_mappings(self, files: list[Path]) -> list[RenameMapping]:
        """
        为文件列表生成重命名映射。

        Args:
            files: 扫描得到的文件路径列表

        Returns:
            RenameMapping 列表（包含匹配和未匹配的文件）
        """
        ...

    def _compile_pattern(self) -> re.Pattern:
        """编译正则表达式，根据 ignore_case 设置标志"""
        ...
```

### 4.3 核心算法

**build_mappings() 算法（伪代码）**:

```
function build_mappings(files):
    mappings = []
    regex = _compile_pattern()

    for file in files:
        old_name = file.name  // 仅文件名部分
        new_name = regex.sub(config.replacement, old_name)

        if new_name == old_name:
            // 未匹配，仍然加入映射（状态标记为 SKIPPED）
            mapping = RenameMapping(
                original_path=file,
                new_name=old_name,
                matched=False,
                status=RenameStatus.PENDING
            )
        else:
            // 验证新文件名合法性
            validate_new_name(new_name)
            mapping = RenameMapping(
                original_path=file,
                new_name=new_name,
                matched=True,
                status=RenameStatus.PENDING
            )

        mappings.append(mapping)

    return mappings

function _compile_pattern():
    flags = re.IGNORECASE if config.ignore_case else 0
    return re.compile(config.pattern, flags)
```

## 5. 模块 4：冲突检测器 (conflict.py) 详细设计

### 5.1 模块概述

在重命名执行前，检测目标文件名是否会产生冲突。

### 5.2 类/接口定义

```python
from config import RenameMapping, ConflictInfo

class ConflictDetector:
    """文件名冲突检测器"""

    def detect(self, mappings: list[RenameMapping]) -> list[ConflictInfo]:
        """
        检测重命名映射中的冲突。

        仅检查 matched=True 的映射。
        冲突类型：
        1. 两个不同的源文件映射到相同的目标文件名（同一目录下）
        2. 目标文件名与现有未参与重命名的文件重名

        Args:
            mappings: 重命名映射列表

        Returns:
            冲突信息列表，无冲突时为空
        """
        ...
```

### 5.3 核心算法

**detect() 算法（伪代码）**:

```
function detect(mappings):
    conflicts = []
    matched_mappings = [m for m in mappings if m.matched]

    // 按父目录分组
    groups = group_by_parent_directory(matched_mappings)

    for parent_dir, group in groups.items():
        // 检查组内目标名冲突
        seen = {}  // target_name -> RenameMapping
        for mapping in group:
            target = mapping.new_name
            if target in seen:
                conflicts.append(ConflictInfo(
                    target_name=target,
                    conflicting_paths=[seen[target].original_path, mapping.original_path]
                ))
            else:
                seen[target] = mapping

        // 检查与现有非参与文件冲突
        if not config.force:
            existing_files = set(列出该目录下所有文件名)
            for mapping in group:
                if mapping.new_name in existing_files:
                    // 目标名与同名未参与文件冲突
                    // 检查是否指向自身（无操作）
                    if mapping.new_name != mapping.original_path.name:
                        conflicts.append(ConflictInfo(
                            target_name=mapping.new_name,
                            conflicting_paths=[mapping.original_path, parent_dir / mapping.new_name]
                        ))

    return conflicts
```

### 5.4 数据结构设计

- 输入：`list[RenameMapping]`
- 输出：`list[ConflictInfo]`

### 5.5 状态转换图

冲突检测器自身无状态，仅影响 `RenameMapping.status`（设置为 `CONFLICT`）。

### 5.6 异常处理策略

| 异常场景 | 处理方式 |
|----------|----------|
| 无法读取目录内容 | 捕获 `PermissionError`，将冲突检测范围限于可读目录，输出警告 |

### 5.7 模块测试要点

- 无冲突场景返回空列表
- 两个文件映射到同一目标名
- 目标名与现有文件冲突
- 多个冲突同时检测
- 仅检查 matched=True 的映射
- force 模式下跳过现有文件冲突检查

```python
        Returns:
            RenameResult 包含执行统计
        """
        ...

    def _rename_one(self, mapping: RenameMapping) -> None:
        """重命名单个文件并更新状态"""
        ...
```

### 6.3 核心算法

**_rename_one() 算法（伪代码）**:

```
function _rename_one(mapping):
    try:
        if mapping.new_path.exists() and not self.force:
            mapping.status = RenameStatus.CONFLICT
            return

        mapping.original_path.rename(mapping.new_path)
        mapping.status = RenameStatus.SUCCESS

    except FileExistsError:
        mapping.status = RenameStatus.CONFLICT
    except PermissionError:
        mapping.status = RenameStatus.FAILED
    except OSError as e:
        mapping.status = RenameStatus.FAILED

function execute(mappings):
    result = RenameResult()

    for mapping in mappings:
        if not mapping.matched:
            mapping.status = RenameStatus.SKIPPED
            result.skip_count += 1
            continue

        _rename_one(mapping)

        if mapping.status == RenameStatus.SUCCESS:
            result.success_count += 1
        elif mapping.status == RenameStatus.CONFLICT:
            result.conflict_count += 1
        elif mapping.status == RenameStatus.FAILED:
            result.fail_count += 1

        result.mappings.append(mapping)

    return result
```

### 6.4 数据结构设计

- 输入：`list[RenameMapping]`
- 输出：`RenameResult`

### 6.5 状态转换图

参见 config 模块的状态转换图。

### 6.6 异常处理策略

| 异常场景 | 处理方式 |
|----------|----------|
| 目标文件已存在 | 非 force 模式下设置状态为 CONFLICT，继续处理后续文件 |
| 权限不足 | 设置状态为 FAILED，继续处理后续文件 |
| 磁盘 I/O 错误 | 设置状态为 FAILED，继续处理后续文件 |
| 源文件在执行过程中被删除 | 设置状态为 FAILED |

**设计决策**：单文件失败不影响其他文件的处理。采用"尽力而为"策略，尽可能多地完成重命名。

**print_dry_run() 算法（伪代码）**:

```
function print_dry_run(mappings):
    matched = [m for m in mappings if m.matched]
    unmatched = [m for m in mappings if not m.matched]

    print(f"\n扫描到 {len(mappings)} 个文件，{len(matched)} 个将重命名，{len(unmatched)} 个跳过\n")

    if matched is empty:
        print("没有文件需要重命名。")
        return

    // 计算列宽
    max_old_len = max(len(m.original_path.name) for m in matched)
    max_new_len = max(len(m.new_name) for m in matched)
    max_old_len = max(max_old_len, 8)   // 最小宽度适配表头
    max_new_len = max(max_new_len, 8)

    // 打印表头
    print_header("原文件名", "新文件名", max_old_len, max_new_len)
    print_separator(max_old_len, max_new_len)

    // 打印每行
    for m in matched:
        print_row(m.original_path.name, m.new_name, max_old_len, max_new_len)

    print_separator(max_old_len, max_new_len)
    print(f"\n共 {len(matched)} 个文件将被重命名。")
    print("使用不带 --dry-run 参数运行以执行重命名。")

function print_result(result):
    print(f"\n重命名完成：成功 {result.success_count}，跳过 {result.skip_count}，失败 {result.fail_count}")

    if result.conflict_count > 0:
        print(f"冲突 {result.conflict_count}（使用 --force 覆盖）")
```

### 8.3 核心算法

**main() 算法（伪代码）**:

```
function main(argv):
    try:
        config = parse_args(argv)

        // 1. 扫描文件
        scanner = FileScanner(config)
        files = scanner.scan()

        if files is empty:
            print("未找到匹配的文件。")
            return 0

        // 2. 正则匹配与替换
        engine = RenameEngine(config)
        mappings = engine.build_mappings(files)

        // 3. 冲突检测
        detector = ConflictDetector()
        conflicts = detector.detect(mappings)

        if conflicts is not empty and not config.force:
            reporter.print_conflicts(conflicts)
            return 2

        // 4. dry-run 或执行
        reporter = Reporter()
        if config.dry_run:
            reporter.print_dry_run(mappings)
            return 0

        // 5. 执行重命名
        executor = RenameExecutor(force=config.force, verbose=config.verbose)
        result = executor.execute(mappings)
        reporter.print_result(result)

        return 0 if result.fail_count == 0 else 2

    except FileNotFoundError as e:
        print(f"错误：路径不存在 - {e}", file=sys.stderr)
        return 1
    except PermissionError as e:
        print(f"错误：权限不足 - {e}", file=sys.stderr)
        return 2
    except re.error as e:
        print(f"错误：正则表达式无效 - {e}", file=sys.stderr)
        return 1
    except ValueError as e:
        print(f"错误：{e}", file=sys.stderr)
        return 1
    except Exception as e:
        print(f"未知错误：{e}", file=sys.stderr)
        return 2
```

| recursive | `-R` | `--recursive` | flag | 否 | False | 递归子目录 |
| dry_run | - | `--dry-run` | flag | 否 | False | 预览模式 |
| filter | `-f` | `--filter` | str | 否 | None | glob 过滤 |
| ignore_case | `-i` | `--ignore-case` | flag | 否 | False | 忽略大小写 |
| force | - | `--force` | flag | 否 | False | 强制覆盖 |
| verbose | `-v` | `--verbose` | flag | 否 | False | 详细输出 |

### 10.2 错误码定义

| 退出码 | 含义 | 场景 |
|--------|------|------|
| 0 | 成功 | 操作完成，无错误（dry-run 也返回 0） |
| 1 | 参数错误 | 无效正则、路径不存在、参数缺失等 |
| 2 | 操作错误 | 文件名冲突、权限不足、部分文件失败 |
