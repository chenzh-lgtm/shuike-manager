### 4.5 核心算法：图书删除校验

```
算法: deleteBook
输入: bookId
输出: void 或抛出异常
步骤:
  1. 根据 bookId 查询 Book 实体，不存在则抛出 EntityNotFoundException
  2. 比较 book.availableCopies 与 book.totalCopies
  3. 如果 availableCopies < totalCopies，说明有书未归还
     抛出 BusinessException("该图书尚有外借记录，无法删除")
  4. 否则，调用 bookRepository.delete(book)
```

```java
public interface BorrowRecordRepository extends JpaRepository<BorrowRecord, Long> {

    // 校验同一读者是否已借同一本书（未归还）
    boolean existsByBookIdAndReaderIdAndStatus(Long bookId, Long readerId, String status);

    // 查询某读者的未归还记录数（删除读者时校验用）
    long countByReaderIdAndStatus(Long readerId, String status);

    // 分页查询借阅记录
    @Query("SELECT br FROM BorrowRecord br WHERE " +
           "(:readerId IS NULL OR br.readerId = :readerId) AND " +
           "(:bookId IS NULL OR br.bookId = :bookId) AND " +
           "(:status IS NULL OR br.status = :status)")
    Page<BorrowRecord> findByConditions(Long readerId, Long bookId, String status, Pageable pageable);

    // 逾期查询：状态为 BORROWED 且 due_date < 当前日期
    @Query("SELECT br FROM BorrowRecord br WHERE br.status = 'BORROWED' AND br.dueDate < :date")
    List<BorrowRecord> findOverdueRecords(LocalDate date);
}
```

#### 6.3.1 借书算法 (borrowBook)

```
算法: borrowBook
输入: BorrowRequest { bookId, readerId, borrowDays (可选, 默认 30) }
输出: BorrowRecord
步骤:
  1. 校验 readerId 对应的读者是否存在 (调用 readerService.getReaderById)
     - 不存在则抛出 EntityNotFoundException
  2. 校验 bookId 对应的图书是否存在 (调用 bookService.getBookById)
     - 不存在则抛出 EntityNotFoundException
  3. 校验该读者未重复借阅此书:
     - 调用 borrowRecordRepository.existsByBookIdAndReaderIdAndStatus(
           bookId, readerId, "BORROWED")
     - 如果返回 true，抛出 BusinessException("该读者已借阅此书且未归还")
  4. 校验图书可借数量:
     - 调用 bookService.getBookById 获取 book.availableCopies
     - 如果 availableCopies <= 0，抛出 BusinessException("该书已全部借出")
  5. 创建 BorrowRecord:
     - bookId = request.bookId
     - readerId = request.readerId
     - borrowDate = LocalDate.now()
     - dueDate = borrowDate + borrowDays
     - status = "BORROWED"
  6. 更新图书库存: bookService.decreaseAvailableCopies(bookId)
  7. 保存 BorrowRecord: borrowRecordRepository.save(record)
  8. 返回 BorrowRecord

事务说明: 整个方法 @Transactional，步骤 6 和 7 要么全部成功，要么全部回滚。
```

#### 6.3.2 还书算法 (returnBook)

```
算法: returnBook
输入: borrowRecordId
输出: BorrowRecord
步骤:
  1. 根据 borrowRecordId 查询 BorrowRecord
     - 不存在则抛出 EntityNotFoundException("借阅记录不存在")
  2. 校验状态:
     - 如果 record.status == "RETURNED"，抛出 BusinessException("该记录已归还")
  3. 更新借阅记录:
     - record.returnDate = LocalDate.now()
     - record.status = "RETURNED"
  4. 更新图书库存: bookService.increaseAvailableCopies(record.bookId)
  5. 保存更新: borrowRecordRepository.save(record)
  6. 返回 BorrowRecord

事务说明: 整个方法 @Transactional。
```

#### 6.3.3 逾期查询算法 (getOverdueRecords)

```
算法: getOverdueRecords
输入: 无（或可选日期截止参数）
输出: List<BorrowRecord>
步骤:
  1. 如果调用方未传入日期参数，使用 LocalDate.now()
  2. 调用 borrowRecordRepository.findOverdueRecords(date)
  3. 返回结果列表
```

## 7. 数据库详细设计

### 7.1 完整 DDL

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS library_management
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_unicode_ci;

USE library_management;

-- 图书表
CREATE TABLE book (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    isbn VARCHAR(20) NOT NULL UNIQUE,
    title VARCHAR(200) NOT NULL,
    author VARCHAR(100) NOT NULL,
    publisher VARCHAR(100),
    publish_year INT,
    category VARCHAR(50),
    location VARCHAR(100),
    total_copies INT NOT NULL DEFAULT 1,
    available_copies INT NOT NULL DEFAULT 1,
    version BIGINT DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT chk_copies CHECK (available_copies <= total_copies AND available_copies >= 0)
) ENGINE=InnoDB;

-- 读者表
CREATE TABLE reader (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    phone VARCHAR(20) NOT NULL UNIQUE,
    email VARCHAR(100),
    reader_type VARCHAR(20) NOT NULL DEFAULT '普通',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB;

-- 借阅记录表
CREATE TABLE borrow_record (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    book_id BIGINT NOT NULL,
    reader_id BIGINT NOT NULL,
    borrow_date DATE NOT NULL,
    due_date DATE NOT NULL,
    return_date DATE,
    status VARCHAR(20) NOT NULL DEFAULT 'BORROWED',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_borrow_book FOREIGN KEY (book_id) REFERENCES book(id),
    CONSTRAINT fk_borrow_reader FOREIGN KEY (reader_id) REFERENCES reader(id),
    CONSTRAINT chk_dates CHECK (due_date >= borrow_date)
) ENGINE=InnoDB;
```

### 7.2 索引设计

```sql
-- 加速读者删除时的校验
CREATE INDEX idx_borrow_reader_status ON borrow_record(reader_id, status);

-- 加速逾期查询
CREATE INDEX idx_borrow_status_duedate ON borrow_record(status, due_date);

-- 加速借书时的重复性校验
CREATE INDEX idx_borrow_book_reader_status ON borrow_record(book_id, reader_id, status);

-- 图书表：加速书名搜索
CREATE INDEX idx_book_title ON book(title);

-- 图书表：加速作者搜索
CREATE INDEX idx_book_author ON book(author);
```

### 7.3 数据迁移策略

本项目为新建系统，无历史数据迁移需求。通过 Spring Data JPA 的 `spring.jpa.hibernate.ddl-auto=update` 配置自动建表（开发阶段），生产环境建议使用 Flyway 或 Liquibase 管理数据库版本。

| 查询不存在的图书 ID | 抛出 EntityNotFoundException |
| 修改已有图书 | 返回更新后的 Book |
| 删除无外借记录的图书 | 成功删除 |
| 删除有外借记录的图书 | 抛出 BusinessException |
